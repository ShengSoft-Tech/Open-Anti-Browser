## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| 首启兜底对话框里的终端命令 → 用户在自己 Mac 上执行的系统操作 | 用户会原样复制粘贴执行。命令写宽了(全局开关 / 提权 / 宽目录递归),后果发生在用户机器上且不可撤回 |
| `sys.executable` 推导出的 bundle 路径 → `subprocess.run(["xattr", ...])` 的参数 | 路径来自进程自省而非用户输入,但推导错误会导致对非预期路径执行递归属性清除 |
| Cmd+Q 事件 → uvicorn 服务与已启动的浏览器子进程 | 退出路径若绕过 `shutdown()`,uvicorn 线程与浏览器会话跟踪不会被正确收尾 |
