<objective>
新增后端平台能力声明:一个 `get_platform_capabilities()` 方法,通过独立端点 `GET /api/capabilities` 暴露,并把同一 capabilities 块并入 `bootstrap()` 返回体(D-01)。字段用显式布尔表达(D-02):per-engine `available`(平台级是否支持,与 `installed`/`capability_ok` 正交)、窗口功能 `arrange`/`sync` 的 `available`+`reason`。

这是本 phase 的 **tracer 纵切**:一条从 service 方法 → route 控制器 → bootstrap 聚合 → HTTP 可观测契约 → 自动化单测的端到端路径。它也是 Phase 3→4 的硬接口(前端门控直接消费字段名/语义),故先证通并经决策门锁定契约。

Purpose: 满足 XPLAT-05 与 ROADMAP SC4(明确写 `GET /api/capabilities`),为 Phase 4 UI-01/UI-02 门控提供单一事实来源。
Output: `get_platform_capabilities()` 方法、`/api/capabilities` 路由、`bootstrap()` capabilities key、`tests/test_capabilities_api.py`。
</objective>
