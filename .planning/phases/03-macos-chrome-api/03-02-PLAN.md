<objective>
把 `kill_process_tree`(backend/services/network.py)从"整棵树立即 SIGKILL"改造为"整棵树 SIGTERM → 宽限窗口 → 对幸存者 SIGKILL"(D-05),减少 macOS 上 `SingletonLock`/profile 损坏。改造为**统一跨平台路径**(D-06),不引入 macOS-only 分支:psutil `terminate()` 在 Windows 上等同 `TerminateProcess`(与现 `kill()` 等价),故 Windows 行为实质不变(零回归)。

Purpose: 满足 LAUNCH-03(停止配置/退出应用正确终止进程树、无残留),同时守住 Windows 零回归硬约束。
Output: 改造后的 `kill_process_tree`、`DEFAULT_TERMINATION_GRACE_PERIOD` 常量、`tests/test_process_termination_macos.py`。
</objective>
